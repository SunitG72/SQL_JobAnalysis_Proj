# The Analysis
Now, time to solve the scenerios. These scenerios will help us get a very good study or analysis of the Data Analyst job market and its various aspects. Here's how I solved these queries:

### 1. Top Paying Data Analyst Jobs
First thing I did is, obviously filter the Data Analyst positions and ordered by highest to lowest average yearly salary. Also removed NULL values from salaries because we dont want that and chose location to be 'Anywhere', you can filter by your specific location.
 ```sql
 SELECT
    company_dim.name,
    job_postings_fact.job_id,
    job_postings_fact.job_title,
    job_postings_fact.job_location,
    job_postings_fact.job_schedule_type, 
    job_postings_fact.salary_year_avg,
    job_postings_fact.job_posted_date
FROM 
    job_postings_fact
LEFT JOIN company_dim
    ON job_postings_fact.company_id = company_dim.company_id
WHERE 
    job_postings_fact.job_title_short LIKE '%Data Analyst%' AND
    job_postings_fact.job_location = 'Anywhere' AND
    job_postings_fact.salary_year_avg IS NOT NULL
ORDER BY
    job_postings_fact.salary_year_avg DESC
LIMIT 10;
 ```
A short breakdown of the result:
- **Wide salary range**: $184K to $650k!
- **Employers**: Companies like Mantys, Meta, AT&T are highest paying for Data Analyst roles.
- **Job Variety**: Theres Directors, Associates and even Marketing roles.

### 2. Skills required for Top Paying Data Analyst Jobs
Next I wanted to see what skills are required for these top paying jobs. To get the skills, I joined the skills data table to our previous top paying jobs result table.
```SQL
WITH top_paying_jobs AS (
    SELECT
        company_dim.name,
        job_postings_fact.job_id,
        job_postings_fact.job_title,
        job_postings_fact.salary_year_avg
    FROM 
        job_postings_fact
    LEFT JOIN company_dim
        ON job_postings_fact.company_id = company_dim.company_id
    WHERE 
        job_postings_fact.job_title_short LIKE '%Data Analyst%' AND
        job_postings_fact.job_location = 'Anywhere' AND
        job_postings_fact.salary_year_avg IS NOT NULL
    ORDER BY
        job_postings_fact.salary_year_avg DESC
    LIMIT 10
)

SELECT 
    top_paying_jobs.*,
    skills_dim.skills
FROM 
    top_paying_jobs
INNER JOIN skills_job_dim 
    ON top_paying_jobs.job_id = skills_job_dim.job_id
INNER JOIN skills_dim
    on skills_job_dim.skill_id = skills_dim.skill_id
ORDER BY
    top_paying_jobs.salary_year_avg DESC;
```
Short breakdown of the findings:
- **The floor is extremely high**: Every single skill in the top 15 averages over $200k!
- **Niche skills pays best**: Specialized tools like Databricks and PySpark top the chart.
- **Common tools average lower**: SQL and Python pay less on average because they're required in lower-tier jobs too.

### 3. Most in-demand Skills for Data Analytics
This query gives us the most demanded skills for data analytics. The skills that frequently appear in job postings.
```sql
SELECT
    skills_dim.skills,
    COUNT(skills_job_dim.job_id) AS demand_count
FROM 
    job_postings_fact
INNER JOIN skills_job_dim 
    ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim
    on skills_job_dim.skill_id = skills_dim.skill_id
WHERE 
    job_postings_fact.job_title_short LIKE '%Data Analyst%'
GROUP BY
    skills
ORDER BY
    demand_count DESC
LIMIT 5;
```
Breakdown of the result:
- **SQL is king**: It dominates the market as the only skill exceeding 100,000 job postings.
- **Excel beats Python**: Traditional spreadsheet proficiency is still requested more frequently than Python programming.
- **BI tools are essential**: Tableau and Power BI round out the top 5, showing strong demand for core data visualization platforms.

### 4. Highest Overall Skill Salaries
This query will grroup the skills and aggregate their salary and arrange in highest to lowest order. This will show us which skills are actually paying the most in average.
```sql
SELECT
    skills_dim.skills,
    ROUND(AVG(job_postings_fact.salary_year_avg), 0) AS avg_salary
FROM 
    job_postings_fact
INNER JOIN skills_job_dim 
    ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim
    on skills_job_dim.skill_id = skills_dim.skill_id
WHERE 
    job_postings_fact.job_title_short LIKE '%Data Analyst%' AND
    job_postings_fact.salary_year_avg IS NOT NULL
GROUP BY
    skills
ORDER BY
    avg_salary DESC
LIMIT 5;
```
Short Breakdown:
- **SVN dominates**: Legacy tech pays the highest by a massive margin ($400k).
- **Infrastructure pays well**: VMware and Yarn both comfortably exceed $200k.
- **Modern tools lag**: Trending skills like FastAPI and Solidity sit at the bottom (<$190k).

### 5. Most Optimal Skills
What this query does is, combines the insights from most demanded and paying skills. This will result in the most optimal skills to learn. I have first filtered out skills where demand is more than 10, and then sorted them by highest to lowest order based on average aggregated salary of the skill.
```sql
SELECT
    skills_dim.skills,
    COUNT(skills_dim.skill_id) AS demand_count,
    ROUND(AVG(job_postings_fact.salary_year_avg), 0) AS avg_salary
FROM 
    job_postings_fact
INNER JOIN skills_job_dim
    ON job_postings_fact.job_id = skills_job_dim.job_id
INNER JOIN skills_dim
    ON skills_job_dim.skill_id = skills_dim.skill_id
WHERE
    job_postings_fact.job_title_short LIKE '%Data Analyst%' AND
    job_postings_fact.salary_year_avg IS NOT NULL
GROUP BY
    skills_dim.skill_id
HAVING
    COUNT(skills_dim.skill_id) > 10
ORDER BY
    avg_salary DESC,
    demand_count DESC
LIMIT 10;
```
